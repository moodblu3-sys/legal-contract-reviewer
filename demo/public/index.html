セキュリティ・ガバナンス
FedRAMP、ISO27001、SOC2認証取得。保険業界の厳格なコンプライアンス要件に対応。7段階のアクセス権限で契約書のアクセスを厳密に管理。
AI機能の内蔵
Box AIはコンテンツの境界内でAI処理を実行。契約書の内容が外部に漏洩するリスクなし。追加のAIインフラ構築が不要。
メタデータ駆動の管理
AIレビュー結果をメタデータとして構造化保存。Metadata Query APIで契約書の横断検索・分析が可能。監査証跡を自動生成。
ワークフロー統合
Box Relay で承認フロー自動化、Box Sign で電子署名、Box Notesで法務コメント共有。契約ライフサイクル全体をBox内で完結。

AI 社内問い合わせ（デモ）

Box に蓄積された契約書・社内文書をもとに、AIが質問に回答します

Box AI 質問応答
Box内の文書をソースとして回答を生成
AI
こんにちは。Box AI 社内問い合わせアシスタントです。 契約書や社内文書に関するご質問にお答えします。 例えば以下のような質問ができます： ・「損害賠償条項のリスクを教えて」 ・「解約条件について確認したい」 ・「秘密保持契約の期間は？」
このユースケースのアーキテクチャ

社内問い合わせのAI化は、Box AI Ask の機能だけでは対話型UIの提供が困難なため、 外部LLM（Claude等）を組み合わせるアーキテクチャを採用します。

外部AI採用の根拠： Box AI Ask は単一・複数ファイルに対するQAに優れていますが、対話コンテキストの維持や 複雑な推論が必要な問い合わせ対応には、外部LLMとの組み合わせが効果的です。 Box API でコンテンツを安全に取得し、LLM にはコンテキストのみを渡すことで、 データの安全性を確保しながら高品質な回答を生成します。
